\section{The Faraday tensor of the plane wave}

The Faraday tensor of the plane wave is given by
\begin{align}
    F^{\mu\nu}(x) = \partial^\mu A^\nu(x) - \partial^\nu A^\mu(x).
\end{align}
For a plane wave described by the vector potential \eqref{eq:plane_wave}, we obtain
\begin{align}
    F^{\mu\nu}(x) = A_0 k \left[f'(k \phi)\Re\{(n^\mu s^\nu - n^\nu s^\mu) e^{ik \phi}\} +  f(k\phi)\Re\{i(n^\mu s^\nu - n^\nu s^\mu) e^{ik\phi}\}\right]
\end{align}
