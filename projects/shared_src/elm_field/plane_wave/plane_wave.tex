

\section{The vector potential of the plane wave}

A plane wave is a field propagating in the ${\bf n}$ direction.

With the notations
\begin{align}
    n = (1,{\bf n}), \qquad k = \frac{\omega}{c}, \qquad \phi = n\cdot x, \qquad \omega = ck_0,
\end{align}

we write the plane wave as
\begin{align}
     & A(x) = A_0f(k\phi)\Re\{s {\mathrm e}^{{\mathrm i} k\phi}\},\label{eq:plane_wave}
\end{align}

where $f$ is the envelope of the wave and $s$ is the complex polarization vector of the wave. The polarization vector must obey the orthogonality relation
\begin{align}
    s\cdot n = 0,
\end{align}
and the normalization relation
\begin{align}
    s^* \cdot s = -1.
\end{align}
